Apresentação da Pesquisa

Bem-vindo ao portal de avaliação institucional de questionários. Este projeto tem como objetivo principal coletar dados essenciais sobre o ambiente organizacional, a infraestrutura e a qualidade dos serviços prestados pela nossa instituição.

A sua participação é fundamental para construirmos um ambiente melhor. Todas as respostas fornecidas nestes questionários são anônimas e serão tratadas com total confidencialidade, servindo exclusivamente para fins de melhoria contínua e análise acadêmica/administrativa.

Como Funciona?

Para participar e preencher os questionários, siga os passos abaixo:

  1. Acesse o Menu de Navegação acima.
  2. Clique em Fazer Login para autenticar-se no sistema usando suas credenciais institucionais.
  3. Após o login, você será redirecionado para a tela principal ( Área do Usuário )
  4. Selecione a pesquisa desejada e responda com sinceridade.

Dúvidas Frequentes

Quem pode participar? Alunos e professores devidamente matriculados.

Quanto tempo leva? Cada questionário leva em média de 5 a 15 minutos para ser concluído.
